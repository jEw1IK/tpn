# Спецификация поведения калькулятора mytpn.ru (публичная версия 2026.08.04)

Источники: (1) наблюдения в публичной форме https://mytpn.ru/online/calculator/neonatal через Playwright (скрипты в `scratchpad/mytpn/probes/*`, лог сводной проверки `probes/verify-core/run.out`, зонды энтерального питания `probes/enteral/*`, каталоги препаратов `data/antibiotics_catalog*.json`, `data/antifungal-hormone-analeptic-observations-*.json`); (2) модуль калькулятора и хранилище Vuex из публичного бандла `/js/app.js` (поле за полем сверено с наблюдениями; код не копировался, здесь только правила); (3) руководство пользователя и описание функций ПО с mytpn.ru/reestr-po; (4) КР РАСПМ «Парентеральное питание новорождённых», 2015.

Обозначения: `кг` = вес для счёта / 1000 (поле «Вес для счёта (гр)»), если не сказано иное. `r1(x)` = округление до 1 знака (`toFixed(1)`), `r2` — до 2 знаков, `r0` — до целого. Отрицательные результаты заменяются нулём (внутренний фильтр `pe`: значение < 0 → 0).

## 2. Поля препаратов (прогрессивное раскрытие)

Общее: после выбора препарата появляется первое поле; следующее поле активируется только когда заполнено предыдущее; незаполненное обязательное поле подсвечивается статусом (dinamic-status), цвет рамки по группе (антибиотики зелёный, гормоны коричневый, противогрибковые фиолетовый, аналептики розовый, кровь оранжевый, другие синий). Кнопка «Добавить препарат» переносит строку в лист и очищает блок.

### 2.1. Антибиотики, противогрибковые/противовирусные, гормоны, аналептики (базовый блок)
1. Разовая доза, подпись «Разовая доза мг/кг» (ci из справочника); подсказка `dosirovka`.
2. Интервал (часы) — любое число; 24 и меньше → часы введения считаются; > 24 → в листе «Пропуск» или дата первого введения по истории (нужны сохранённые листы).
3. Нагрузочная доза (мг/кг, необязательно) и Время первого введения (HH:MM) — активируются одновременно после интервала.
4. Путь введения: в/в, в/в (за 30 мин), в/в (за 1 час), в/в микроструйно, в/м, per os, подкожно, эндотрахеально.
5. Раствор для разведения (Вода для инъекций, NaCL 0.9%, Глюкоза 5%) и «Развести до (мл)» — показываются только для антибиотиков (и наркотических), после выбора пути; заполняются при любом пути, включая per os.

Строка листа: `«Имя - D мг»`, где D = `r2(доза · d7/1000)` (вес сегодня!), затем при нагрузочной дозе `(L мг нагр.доза)`, L = `r1(нагр · d7/1000)`; затем путь введения; при растворителе — `(Растворитель до V мл.)`; затем часы введений; затем `(Nдн.)` — номер дня терапии (в публичной версии всегда «(1дн.)»). Пример: `Ампициллин - 65.00мг в/в (Вода для инъекций до 2 мл.) 08:00 20:00 (1дн.)`.

### 2.2. «Другие»
1. Единицы (select): мг, мг/кг, мкг, мкг/кг, мл, мл/кг, гр, гр/кг, кап, кап/кг, саше, свеча, МЕ, МЕ/кг, дозы — подпись дозы меняется на выбранную единицу.
2. Разовая доза → 3. Интервал → 4. Нагрузочная доза + Время первого введения → 5. Путь введения: в/в, в/в (за 30 мин), (за 1 час), (за 2 часа), (за 3 часа), (за 4 часа), (за 5 часов), (за 6 часов), (за 12 часов), (за 24 часов), в/в микроструйно, в/м, per os, подкожно, эндотрахеально, ректально, ингаляции, в 2 глаза → 6. Раствор для разведения и «Развести до (мл)» (всегда после пути).

Доза в листе: если единица содержит «/кг» → `r1(доза · d7/1000)` + единица без «/кг» (например «Вит D - 500МЕ per os»), иначе доза как введена.

### 2.3. Препараты крови
Поля: Разовая доза (мл/кг) → Время первого введения → Путь введения (в/в, в/в (за 30 мин), (за 1 час), (за 2 часа), (за 3 часа), (за 4 часа), (за 5 часов), (за 6 часов)). Интервала нет. Объём = `r2(доза·d7/1000)` мл; в жидкость суток **не входит** и в «жидкость вне инфузии» не входит.

### 2.4. Кардиотоники
Поля: препарат (select), Доза (мкг/кг/мин), Раствор для разведения, Развести до (мл) (по умолчанию 12), Скорость (мл/час) (по умолчанию 0,5). Строка: `Дофамин 4% 0.23 мл + NaCL 0.9% до 12 мл | 0.5 мл/час`, где мл препарата = `r2(кг · доза · V · 60 / (10 000 · % · скорость))` (кг = вес для счёта b7). Объём V каждой заполненной строки входит в жидкость вне инфузии (t10).

### 2.5. Инсулин
Ввод в Ед/кг/час. В листе: `Инсулин O Ед + Вода для инъекций до 12 мл | 0.5 мл/час (a Ед/кг/час)`, O = `r3(a · d7/1000 · 24)` (суточная доза). Наличие инсулина добавляет **12 мл** в жидкость вне инфузии (t10).

### 2.6. Часы введений
Для интервала I (ч) и первого времени T: число введений `a+1`, где `a = round(24/I − 1)` (0 при I ≥ 36); времена `T + k·I`, при ≥ 24 вычитается 24; формат `HH:MM` (минуты сохраняются). Примеры: I=12,T=08:00 → 08:00 20:00; I=8,T=10:00 → 10:00 18:00 02:00; I=6,T=08:00 → 08:00 14:00 20:00 02:00; I=24 → одно; I=36/48 → одно время (и в закрытой версии счёт по дате прошлого введения).

## 3. Формулы

### 3.1. Энтеральное питание
- `n26` = сумма всех объёмов кормлений всех смесей, мл/сут. `m29 = r2(n26/кг)` — «Смеси/кг».
- **Трофическое правило:** если `m29 ≥ 25` (по весу для счёта), объём каждой смеси учитывается в нутриентах (`j29` = её объём) и общий учтённый объём `J = n26`; иначе `J = 0` и нутриенты смеси = 0. Граница включительно: 25,0 мл/кг уже считается, 24,99 — нет. Поле «Кол-во смеси с учетом нутриентов» показывает учтённый объём.
- Нутриенты смеси i: `Б_i = r2(белок₁₀₀/100 · j29_i)`, аналогично Ж, У, ккал; суммы по смесям `b29, d29, f29, h29` (2 знака).
- Выходы: `l44` = энтерально мл/24 ч = `r1(J или n26)` (то есть объём показывается всегда, даже трофический); `l46 = r1(Б)`, `l47 = r1(Ж)`, `l45 = r1(У)`, `m44 = r1(ккал)`; на кг: `n46 = r1(l46/кг)` и т.д. (`n44` = ккал/кг энтерально).

### 3.2. Объём жидкости
- Объём на ПП (e44) = `r1(b10 · кг − J)` — энтеральное вычитается только когда оно ≥ 25 мл/кг; трофическое идёт **сверх** потребности.
- `o2` = e44 − p17 (эмульсия) − p18 (Виталипид) + d22 (проводник) − f22 (жидкость вне инфузии, введённая врачом) [+ p5 + электролиты, если физ. потребность не задана — служебный случай].
- Полученная инфузия (`o2n`, показывается справа и в листе) = `r1(o2 − p5)` = всё, что идёт в основную линию без аминокислот: глюкоза + электролиты + витамины + проводник.
- Объём на глюкозу `p4 = r1(o2 − p5 − d22 − Σ(p6…p13))` = потребность − энтеральное(≥25) − эмульсия − Виталипид − жидкость вне инфузии − АК − электролиты − Дипептивен − Аддамель − Солувит. Проводник не уменьшает глюкозу (он добавляется и тут же вычитается).
- Жидкости в/в `e54 = r1(p4 + p5 + Σp6…p13 + p14 + p17 + p18 + t10)` = e44 − f22 + d22 + t10.
- Жидкости/сутки `s44 = r1(l44 + e54)`. «Получит (мл/кг)» `s47 = r1(s44 / d7 · 1000)` — **делится на вес сегодня**, не на вес для счёта.
- Жидкость вне инфузии рекомендуемая `h22 = r0(t10)`, где `t10` = Σ по антибиотикам, «Другим» и наркотическим: `(24/интервал) · объём «Развести до»` (для любого пути введения, включая per os, если объём заполнен) + Σ объёмов «Развести до» всех кардиотоников + 12 мл при инсулине. Препараты крови, противогрибковые, гормоны и аналептики **не учитываются** (у них растворитель не запрашивается). Нагрузочная доза объём не добавляет (пока `ci_to_ml` пуст).
- Пока `f22 ≠ h22`, поле «Жидкость вне инфузии» жёлтое со статусом. Если врач вводит `f22 = h22`, растворители перестают быть «сверх» и вычитаются из объёма глюкозы, и `e54` снова = потребность.

### 3.3. Глюкоза
- Грамм в сутки `e45 = r2(d10 · кг · 1.44 − l45)` — из в/в глюкозы вычитаются **округлённые до 0,1 г** энтеральные углеводы (только при ≥ 25 мл/кг). Если результат < 0 → 0.
- Глюкоза в/в (мг/кг/мин) `e48 = r1((e45/1.44)/кг)`; в шапке «Глюкоза общ. / в/в»: `d10 / e48`.
- Концентрация в объёме глюкозы `n4 = r1(100 · e45 / p4)`; концентрация во всей полученной инфузии `p19 = r1(100 · e45 / o2n)` (показывается рядом с «Полученная инфузия»).
- Подбор из двух растворов: `s22 = n4 − q23`, `s23 = r1(q22 − n4)`, `p26 = p4 / (s22 + s23)`; объём большего раствора `t22 = r1(s22 · p26)`, меньшего `t23 = r1(s23 · p26)`. Если `q23 ≥ floor(n4)` при q23 = 0 или 0.9, строка типа показывает «Вода для инъекций» / «NaCl 0.9%» вместо «Глюкоза n4%».
- Опции «Больший %»: 40/20/10/5 показываются только если `n4 ≤` опции; «Меньший %»: 0 всегда, 0.9/5/10/20 только если `n4 ≥` опции. Строка «Больший %» подсвечивается (dinamic-clucosa), если n4 > 0 и q22 не выбран или n4 > q22; «Меньший %» — если n4 > 0 и q23 не выбран.
- Предупреждение (модальное): при вводе GIR, если `n4 > 40` — «Выполнить условие невозможно! Итоговый процент глюкозы больше 40%. Необходимо уменьшить дотацию глюкозы или увеличить физ. потребность.»; поле GIR получает статус-подсветку.
- Предела 12,5 % для периферии в программе **нет**.
- Скорость основной линии `t9 = r1((p4 + Σp6…p13 + d22) / 24)` мл/час (подписана в строке NaCl 10 %, data-test …-hour) — АК не входят (отдельный шприц), если не включён режим «старые аминокислоты».

### 3.4. Белки и жиры
- Белок в/в `e46 = r1(f10 · кг − l46)` (энтеральный белок, округлённый до 0,1, вычитается при ≥ 25 мл/кг). Аминовен 10 %: `p5 = r1(10 · e46)` мл.
- Скорость АК `p51 = r2(p5 / (24 − N/2))`, где N — число введений за сутки всех антибиотиков с интервалом < 25 ч (каждое введение антибиотика «съедает» полчаса линии АК).
- Жиры в/в `e47 = r1(h10 · кг − l47)`. Эмульсия 20 %: `p17 = r1(5 · e47)`; 10 %: `r1(10 · e47)`. Виталипид `p18 = r1(q · кг)`. Скорость эмульсии `r17 = r1((p17 + p18) / 20)` — **за 20 часов**.
- Подсветка: белок введён, а АК не выбраны → статус у select АК; жиры введены, а эмульсия не выбрана → статус у select эмульсии. Ограничений доз (max г/кг) **нет**.

### 3.5. Гепарин
`p15 = round(h19 · (d22 + p4 + p5 + Σp6…p13))` Ед — на весь объём основной линии **включая аминокислоты, электролиты и проводник**, без эмульсии. По умолчанию 0,5 Ед/мл.

### 3.6. Калории
- `f45 = r1(4 · e45)` (глюкоза 4 ккал/г), `f46 = 0` (**аминокислоты не считаются**), `f47 = r1(9 · e47)` (жиры 9 ккал/г), `f44 = r1(f45 + f46 + f47)` — ккал парентерально.
- Всего ккал `s45 = r1(f44 + m44)` (плюс энтеральные), ккал/кг `s46 = r1(s45/кг)`.

### 3.7. Динамика массы
`f7 = d7 − f3` (г/сут), `f8 = r1(100·(d7 − f3)/f3)` %, статус-подсветка при f8 ≤ −4 %; `f9` — % от массы при рождении, подсветка при ≤ −10 %.

## 5. Печатная форма («Лист интенсивной терапии»)

Шапка: дата листа; Дата рождения; Постконцепт. возраст; Диагноз; № истории болезни; Динамика веса за сутки (гр) `f7`; строка 2: Фамилия, Возраст (суток), Пол, Койкодни; строка 3: Вес при рождении, «Физ. потребность / получит (мл/кг): b10 / s47», Белки (гр/кг/сут) f10, Жиры h10, «Глюкоза общ. / в/в (мг/кг/мин): d10 / e48»; строка 4: Вес сегодня d7, Вес для счета b7, Жидкости/сутки s44, Жидкости в/в e54, Всего ккалорий s45, Ккалорий/кг s46; строка 5: «Энтерально l44 (мл): Б l46 Ж l47 У l45 Ккал m44 Б(гр/кг) n46 Ж(гр/кг) n47 У(гр/кг) n45 Ккал/кг n44».

Сетка часов: 24 столбца **8, 9, …, 24, 1, …, 7** (сутки с 08:00). Таблица инфузии (строки показываются только при ненулевом значении): Полученная инфузия `o2n мл` `p19%`; проводник `p14 мл`; `Глюкоза q22%  t22 мл` с фигурной скобкой и общей скоростью `t9 мл/час`; `Вода для инъекций / NaCL 0.9% / Глюкоза q23%  t23 мл`; Кальция глюконат 10% `p6 мл`; MgSO4 25% `p7`; `KCl 4% (q ммоль/кг)  p8 мл`; `NaCl 0.9% (q ммоль/кг)  p9`; `NaCl 10% (q ммоль/кг)  p10`; Аддамель Н; Дипептивен; Солувит; Гепарин `p15 Ед`; Аминовен Инфант 10% `p5 мл  p51 мл/час`; эмульсия `p17 мл` `r17 мл/час` (скобка на Виталипид); Виталипид `p18 мл`; Инсулин. Затем кардиотоники, препараты крови, антибиотики, противогрибковые, гормоны, аналептики, другие — по одной строке на препарат (текст из 2.1–2.4), часы введения перечислены текстом в первой ячейке (отметки в столбцах часов не ставятся — столбцы пустые для ручных отметок). Затем «Венозный доступ» (или строки катетеров), строки «Дополнительные назначения» (по одной на строку текста), «Фототерапия (билирубин N мкмоль/л)», исследования (по 3 в строке с временами), смеси: `Имя (мл) ч/з <Соска/Зонд>` с объёмами в столбцах 9, 12, 15, 18, 21, 24, 3, 6, затем строки «Остаточный объем» и «Фактически» (пустые). Высота листа ограничена: число пустых строк = 28 − 2·(препаратов) − (строк инфузии) − (кардиотоников).

Печать в публичной версии — та же страница в режиме печати (не popup), формат A4 альбомный.

«Разделить инфузию»: основной раствор делится на `f = max(2, ceil(o2/50))` шприцев (по 50 мл): в каждый — глюкоза q22 % `t22/f`, разбавитель `t23/f`, гепарин `p15/f`, NaCl 0,9 % `p9/f`, Аминовен `p5/f`, KCl `p8/f`; MgSO4 целиком в шприц 1; кальция глюконат — во все шприцы кроме первого, если есть MgSO4 (несовместимость), иначе во все; Аддамель — в шприц 2; NaCl 10 %, Дипептивен, Солувит — во все, кроме первого; скорость шприца = (сумма объёмов без гепарина) / (24/f).

## 6. Предупреждения и подсветки (сводно)

| Условие | Где | Вид |
|---|---|---|
| f22 ≠ рекомендованной (t10) | Жидкость вне инфузии | жёлтая рамка + статус |
| n4 > 40 | GIR | статус + модальное окно «Выполнить условие невозможно!…» |
| q22 не выбран или n4 > q22 | строка «Больший %» | dinamic-clucosa |
| q23 не выбран | строка «Меньший %» | dinamic-clucosa |
| белок задан, АК не выбраны / жиры заданы, эмульсия не выбрана | селекты | статус |
| вес сегодня ≠ вес для счёта | Вес для счёта | dinamic-clucosa |

## 7. Сверка с КР РАСПМ 2015

Совпадает: порядок расчёта (жидкость → ПП с учётом энтерального → белок → жиры → электролиты → витамины → углеводы → объём на глюкозу → подбор из двух концентраций → лист → скорости); трофическое питание до 25 мл/кг не учитывается (в КР — «менее 25», в программе граница 25 включительно считается уже не трофикой); белок г = m·доза, 10 % АК ×10; жиры 20 % ×5, 10 % ×10; глюкоза г = GIR·m·1,44; вычитание энтеральных Б/Ж/У при частичном ПП; формула подбора двух концентраций; калории = жиры·9 + глюкоза·4, АК не считаются (раздел 12 КР; раздел 4 даёт 10 ккал/г жира, раздел 5 — 3,4 ккал/г глюкозы — внутреннее противоречие КР, программа следует разделу 12); гепарин 0,5–1 Ед/мл; Солувит 1 мл/кг, Виталипид 4 мл/кг в эмульсию; натрий 10 % — коэффициент 1,7 ммоль/мл (как в формуле КР «объём NaCl 10% = m·доза / 1,7»); электролиты: Ca 1–2 мл/кг глюконата, Mg 0,2 мл/кг 25 % (КР Таблица 3).

Отличия/вне КР: KCl 4 % — 0,56 ммоль/мл (КР: 0,54 ммоль/мл и формула ×1,85); NaCl 0,9 % — 0,15 ммоль/мл (КР тоже 0,15); скорость эмульсии за 20 ч (КР: за 24 ч); скорость АК с вычетом получасов на антибиотики (в КР нет); растворители антибиотиков учитываются только после ручного ввода «жидкости вне инфузии» (КР: входят в объём всегда); «получит мл/кг» на вес сегодня при расчёте на вес для счёта; нет контроля 12,5 % и осмолярности (КР раздел 15); нет таблицы потребности в жидкости по массе/возрасту (врач вводит сам); нет пределов доз.
