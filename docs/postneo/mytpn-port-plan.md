# План переноса логики mytpn (КР РАСПМ 2015) в POSTNEO

Основание: `mytpn-spec.md` (поведение эталона) и карта нашего движка (`postneo-map/engine.md`, `nutrition.md`, `sheet.md`, исходники `lib/tpn.ts`, `lib/nutrition.ts`, `lib/nurse-sheet.ts`, `lib/nurse-working-sheet.ts`, `components/nurse-sheet.tsx`, `app/calculator/page.tsx`).

## 1. Что уже совпадает
- Глюкоза г/сут = GIR·кг·1,44; подбор из двух концентраций (у нас — любые проценты, у mytpn фиксированные 40/20/10/5 и 0/0,9/5/10/20).
- Белок: наша «общая цель белка» минус энтеральный белок = в/в аминокислоты, 10 % → ×10 мл. Это и есть e46/p5 mytpn при энтеральном ≥ 25 мл/кг.
- Жиры: г = доза·кг, 20 % → ×5, 10 % → ×10.
- Растворители периодических препаратов входят в суточный объём (КР, раздел 10.1); mytpn требует ручного ввода «жидкости вне инфузии».
- Печатный лист с сеткой 24 часов от начала расчётных суток (08:00), строки препаратов с временами введений, нагрузочные дозы.
- Таблица физпотребности по КР 2015 (у mytpn её нет).

## 2. Расхождения и решения

| № | Тема | mytpn / КР | У нас сейчас | Решение |
|---|---|---|---|---|
| 1 | Трофическое питание | < 25 мл/кг (по весу для счёта): объём сверх потребности, нутриенты не учитываются; ≥ 25 — вычитается из объёма, Б/Ж/У вычитаются из в/в доз | энтеральное всегда вычитается, белок всегда учитывается | Поле `trophicRule`: «по КР (до 25 мл/кг сверх объёма)» по умолчанию / «всегда вычитать». Углеводы и жиры смеси тоже вычитаются из в/в дозы при ≥ 25 мл/кг |
| 2 | Два веса | Вес сегодня (дозы препаратов, «получит мл/кг») и вес для счёта (питание) | одна «расчётная масса» | Поля `weightToday`, `weightYesterday`, `birthWeight`; `weight` = вес для счёта. Динамика г/сут и % (подсветка ≤ −4 %/сут, ≤ −10 % от рождения) |
| 3 | Электролиты и витамины | KCl 4 % (ммоль/кг, 0,56 ммоль/мл), NaCl 10 % (ммоль/кг, 1,7), NaCl 0,9 % (ммоль/кг, 0,15), MgSO4 25 % (мл/кг), Ca глюконат 10 % (мл/кг), Солувит (мл/кг), Виталипид (мл/кг, в эмульсию), Аддамель (мл), Дипептивен (мл/кг) | только кальций (ммоль/кг + ммоль/мл) | Добавить все позиции; кальций оставить в ммоль/кг с подсказкой пересчёта (1 мл/кг 10 % глюконата = 0,225 ммоль/кг). Объёмы входят в основную линию и вычитаются из объёма на глюкозу |
| 4 | Гепарин | Ед/мл (0,5) × объём основной линии (глюкоза + АК + электролиты + проводник) → Ед/сут | нет | Поле `heparin`, вывод Ед/сут |
| 5 | Инсулин | Ед/кг/ч → Ед/сут; шприц 12 мл, 0,5 мл/ч; +12 мл в жидкость | нет | Поля `insulin`; строка в листе; 12 мл в объём лекарств |
| 6 | Проводниковый раствор | имя + мл, сверх потребности, в скорость основной линии и в гепарин | нет | Поля `carrier`, `carrierMl` |
| 7 | Скорости | основная линия /24; АК /(24 − 0,5·число введений антибиотиков); эмульсия (+Виталипид) /20 | все /заданные часы (24) | АК: переключатель «пауза на антибиотики» (по умолчанию вкл.); жиры по умолчанию 20 ч (поле остаётся) |
| 8 | Калории | глюкоза 4, жиры 9, АК 0 (КР раздел 12) | по этикеткам, АК 4 ккал/г | Добавить строку «ккал по КР (небелковые)»: глюкоза·4 + жиры·9 + энтеральные; существующий расчёт по этикеткам сохранить |
| 9 | Справочник препаратов | 7 групп, 81 позиция, подсказки доз, единицы («Другие»: мг…дозы), пути (в/в … в 2 глаза), растворители (вода/NaCl/глюкоза 5 %), «Развести до», кровь (мл/кг, длительность), кардиотоники (% раствора, шприц 12 мл, 0,5 мл/ч) | 8 препаратов, 3 группы | Новый справочник `lib/directory.ts` на основе mytpn (подсказки доз из их справочника с пометкой «проверить по инструкции»), группы: антибиотики, противогрибковые/противовирусные, гормоны, аналептики, другие, препараты крови, вазоактивные (кардиотоники), седация. Поля препарата: единица дозы, путь, растворитель, «развести до», время введения из пути («за 30 мин/1 час/…») |
| 10 | Дозы препаратов | по весу сегодня | по расчётной массе | по `weightToday` (если пусто — по весу для счёта) |
| 11 | Препараты крови | мл/кг, в жидкость не входят | нет | группа «Препараты крови», объём считается, в баланс не входит (флаг) |
| 12 | Смеси | 10 смесей, несколько строк, 8 кормлений (09, 12, 15, 18, 21, 24, 03, 06), «Соска/зонд», трофика | 4 смеси, 1 строка, режимы мл/кг, мл/сут, объём×кормления | Добавить 10 смесей mytpn, режим «8 кормлений», дополнительные строки смесей, способ (соска/зонд) |
| 13 | Глюкоза % | предупреждение > 40 %; нет 12,5 % | ошибка при невозможной смеси | Добавить предупреждение > 12,5 % (периферический доступ, КР раздел 15) и ошибку > 40 % |
| 14 | Меньшая концентрация | 0 = вода, 0,9 = NaCl 0,9 % (mytpn считает её как 0,9 % глюкозы — ошибка) | число % | Выбор раствора: Глюкоза N % / Вода / NaCl 0,9 % (0 % глюкозы — правильно) |
| 15 | Сводка «получит» | мл/кг на вес сегодня; Б/Ж/У энтерально; ккал/кг | частично | Добавить блок «Получит за сутки» как в mytpn |
| 16 | Печать | строки электролитов, гепарина, проводника, инсулина, кардиотоников; шапка с «Физ. потребность / получит», «Глюкоза общ./в/в»; смеси по часам; «Остаточный объём/Фактически»; разделение на шприцы | своя структура | Дополнить строки; шапку; кормления в сетке; приложение «Шприцы» |
| 17 | Жидкость вне инфузии | ручное поле | автоматически | Переключатель `drugFluid`: «входят в объём (КР)» / «сверх объёма (как в mytpn без ввода)» |
