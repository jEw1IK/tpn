# POSTNEO — исходники приложения

Одно приложение на Next.js 16, две сборки:

| Сборка | Что это | Как собрать |
|---|---|---|
| Статический сайт | главная и открытый калькулятор без входа; лист хранится в браузере. Это `postneo/` в корне репозитория, его раздают сервер и GitHub Pages | `deploy/build-site.sh` (статическая сборка в `../postneo`) или вручную: `output:"export"`, серверные маршруты (`app/api`, `app/login`, `app/setup`, `app/(kart)`) на время сборки убираются |
| Карточки пациентов | тот же калькулятор плюс база пациентов, вход по ролям, листы по датам, журнал, печать. Docker-образ для сервера отделения | `docker compose up -d --build`, подробности в `deploy/README.md` |

## Разработка

    npm install
    npm run dev          # http://localhost:3000, база в ./data/postneo.sqlite
    npm test             # движок, методичка, слой данных
    npx tsc --noEmit -p .

Первый вход в режиме разработки: `/setup` заводит администратора.

## Где что

- `lib/tpn.ts` — движок расчёта (жидкость, глюкоза, белок, жиры, электролиты, натрий, препараты), `lib/directory*.ts` — справочник препаратов и смесей.
- `lib/reference.ts` — методичка: пороги билирубина и трансфузии по КР, нормы ПП. `lib/fluid-need.ts` — таблица 1 КР 2015.
- `lib/sheet-flow.ts` — как лист на новый день вырастает из карточки и вчерашнего листа; `lib/server/*` — SQLite, пользователи, сессии, пациенты, журнал.
- `components/calc/*` — калькулятор «Карточки»; `components/nurse-sheet.tsx` — печатный лист А4; `components/reference-drawer.tsx` — методичка; `components/kart/*` — страницы пациентов.
- `app/api/*` — HTTP-интерфейс; `deploy/` — установка в больнице и демо на нашем сервере; `scripts/backup.mjs` — резервная копия базы.
