# Как доделать интеграцию на своём компьютере

Эта сессия работает в облачном контейнере и до твоего компьютера дотянуться
не может — канала нет, и ПК за роутером снаружи недоступен. Зато Claude Code
можно запустить прямо на компьютере: тогда он видит папку с ботом напрямую
и правит код на месте.

---

## 1. Поставить Claude Code

Claude Code есть как приложение для Mac и Windows, как расширение для
VS Code и JetBrains и как команда в терминале. Ставится один раз,
логин — тот же аккаунт, что и здесь.

## 2. Открыть папку с ботом

Запусти Claude Code в той папке, где лежит код бота. Всё, что он там увидит,
он сможет прочитать и поправить.

## 3. Дать ему этот текст

Скопируй целиком и вставь первым сообщением:

> Привет. У меня телеграм-бот в этой папке, и я хочу подключить к нему
> модуль медицинских шпаргалок и калькулятор билирубина.
>
> Модуль уже готов и лежит в публичном репозитории:
> `https://github.com/jEw1IK/tpn`, ветка
> `claude/telegram-bot-pdf-cheatsheets-sdb289`, каталог `cheatsheets/`.
> Инструкция по установке — `cheatsheets/deploy/README.md`,
> описание модуля — `cheatsheets/README.md`.
>
> Сделай, пожалуйста, так:
> 1. Посмотри, как устроен мой бот: точка входа, фреймворк, где создаётся
>    Dispatcher, как регистрируются роутеры и команды меню.
> 2. Скачай ветку и положи каталог `cheatsheets/` рядом с кодом бота
>    (в репозитории для этого есть `cheatsheets/deploy/install.sh`).
> 3. Впиши подключение роутеров в мой код сам, в правильное место:
>    `cheatsheets.bot.aiogram_router.cheatsheets_router` и
>    `cheatsheets.bot.bilirubin_router.bilirubin_router`.
>    Если у меня не aiogram 3, а что-то другое — адаптируй под мой
>    фреймворк, ядро каталога `cheatsheets/bot/catalog.py` от библиотеки
>    не зависит.
> 4. Добавь команды в меню бота: /shpory и /bili.
> 5. Проверь, что ничего не конфликтует с существующими хендлерами
>    и что бот запускается.
>
> Токен бота нигде не показывай и в репозиторий не коммить.

## 4. Проверить

Запусти бота и напиши ему в личку:

```
/shpory   → меню разделов, кнопка присылает PDF
/bili     → кнопка, открывающая калькулятор
```

---

## Если ставить ничего не хочется

Тогда самый быстрый путь — прислать сюда выжимку по проекту:

```
python cheatsheets/deploy/collect.py
```

Скрипт запускается в папке с ботом и складывает рядом `bot-summary.txt`:
структура проекта, зависимости и точки входа, с автоматически вырезанными
токенами и паролями. Пришли этот файл — и я дам точную инструкцию под твой
код, вместо общей.
