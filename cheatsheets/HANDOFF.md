## 1. Что это

Заказчик — врач-неонатолог, автор телеграм-бота **@postneo**. В боте уже были
PDF-шпаргалки (по врождённой пневмонии и другим темам) и мини-приложение
для расчёта парентерального питания. Задача была: сделать таких шпаргалок
больше, добавить в шпаргалку по ГБН таблицы «когда переливать, когда ОЗПК»,
а потом — калькулятор билирубина с нормами.

Дальше это переросло в отдельный подпроект: генератор PDF, калькулятор,
модуль раздачи из бота и комплект для развёртывания.

## 3. Ключевые решения и почему именно так

**Один источник цифр.** Пороги билирубина лежат в
`cheatsheets/data/bilirubin.json`, и из него читают все трое: таблицы PDF
(`content/_data.py`), калькулятор (`build.py` генерирует `bili/thresholds.js`)
и бот (`bilirubin.py`). Разъехавшиеся на 20 мкмоль/л шпаргалка и калькулятор —
это баг, который никто не заметит, пока не станет поздно.

**Пороги — по КР МЗ РФ, а не по AAP.** Изначально была оцифровка кривых
AAP 2004. Потом выяснилось, что в России действуют критерии Kobe 2017 из
приложения А3.3 КР «Гипербилирубинемия недоношенных» (917_1) и «Неонатальная
желтуха» (916_1). Отличия существенные: для доношенного в 48 ч AAP даёт
ОЗПК 376, КР — 342. Теперь КР основная шкала, AAP осталась переключателем.

Таблицы КР **ступенчатые** — значение действует на весь возрастной интервал.
Для них интерполяция отключена; она работает только для кривых AAP.

**Правило «запас < 50» ограничено снизу.** КР добавляют показание к
интенсивной ФТ, когда до порога ОЗПК осталось менее 50 мкмоль/л. Буквальная
реализация в интервале «менее 24 часов» даёт порог *ниже* порога обычной ФТ,
то есть лестница переворачивается. Эффективный порог ограничен снизу порогом
стандартной ФТ. Это интерпретация, а не текст КР — см. раздел 5.

**Источники собираются из реестра.** `cheatsheets/data/guidelines.json` —
выгрузка рубрикатора МЗ РФ, 57 КР по неонатологии. Шпаргалка ссылается по ID,
строка источника строится сама. Обновится КР — меняешь выгрузку, пересобираешь,
даты и ссылки обновляются во всех PDF. Неизвестный ID роняет сборку.

**Тексты КР можно скачивать напрямую:**
`https://apicr.minzdrav.gov.ru/api.ashx?op=GetClinrecPdf&id=917_1`
Сайт рубрикатора — SPA, но этот эндпоинт отдаёт PDF без авторизации.

## 4. Что проверено

- Сборка валидирует таблицы порогов: длину рядов, лестницу
  «станд. ФТ < интенс. ФТ < ОЗПК» в каждой клетке, неубывание с возрастом.
  Проверено подстановкой битого значения — падает с внятным сообщением.
- Расчёт на Python и в браузере сверен на **136 случаях** по всей сетке
  обеих шкал: расхождений нет. Округление приведено к «половине вверх»
  в обоих местах (встроенный `round()` в Python банковский и давал −1).
- Таблицы Kobe сверены **по изображению страницы** клинрека, не по
  извлечённому тексту: порядок таблиц в тексте не совпал с порядком подписей.
- Скрипты деплоя прогнаны на тестовом каталоге, включая повторную установку
  с сохранением кэша `file_id` и импорт модуля из установленного места.
- `collect.py` проверен на тестовом проекте: токен бота, DSN и API-ключ
  вырезаются.

## 5. Что требует вычитки врачом

Это главное, что нельзя пропустить.

- **Пороги билирубина** взяты дословно из КР — им можно доверять.
  Но **правило «запас < 50» с ограничением снизу** — моя интерпретация.
  Буквальное чтение КР даёт несогласованную лестницу; я выбрал разумное
  прочтение. Отключается одной строкой в `bilirubin.py` и `bili/index.html`.
- **Всё остальное содержание 12 шпаргалок** написано по международным
  источникам и общей практике, а не вычитано по текстам КР. Особенно
  сомнительные места: дозы антибиотиков по ПКВ, пороги трансфузии
  эритроцитов, стартовые параметры ИВЛ, дозы инотропов.
- Где отдельного КР в рубрикаторе нет — это сказано прямо в источниках
  (гипогликемия, судороги новорождённых, НЭК, парентеральное питание,
  реанимация в родзале).

## 6. Что осталось

**Главное:** подключить модуль к боту. Код бота у автора на компьютере,
в репозиториях его нет. Два пути — `cheatsheets/deploy/LOCAL-SETUP.md`.

**Полезное дальше:**
1. Вычитать остальные шпаргалки по текстам КР — эндпоинт выше работает.
   Первые кандидаты: РДС (340_2, от 13.02.2026 — совсем свежие),
   ОАП (43_2), сепсис новорождённых (912_1), ГИЭ (908_1).
2. Новые шпаргалки по темам, для которых КР уже есть: апноэ недоношенных
   (933_1), БЛД (377_2), ВЖК (948_1), полицитемия (909_1), геморрагическая
   болезнь (906_1), ретинопатия недоношенных (107_2), неонатальный
   холестаз (959_1), кандидоз новорождённых (944_1).
3. Включить GitHub Pages — без этого кнопка Web App не работает
   (Telegram требует HTTPS с валидным сертификатом, на голый IP нельзя).
4. Навигация между мини-приложениями: из калькулятора ПП в билирубин
   и обратно. Корневой `index.html` пока не трогали.

**Дальняя цель автора** — экосистема: расчёт ПП с запоминанием пациентов,
база пациентов отделения, агент для написания дневников, референсные
значения. Нынешний подпроект — её часть, и структура под это заложена:
данные отделены от представления, расчёт продублирован для бота и веба.
