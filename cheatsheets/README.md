# Шпаргалки неонатолога — PDF для телеграм-бота

Генератор одностраничных (точнее, 2–4-страничных) PDF-памяток для работы
у постели пациента и модуль, который раздаёт их из бота.

Сейчас в наборе **13 шпаргалок**. Добавить свою — примерно 20 строк в одном файле,
вёрстку писать не нужно.

---

## 2. Как собрать

```bash
cd cheatsheets
pip install -r requirements.txt
python build.py                 # собрать всё
python build.py gbn rodzal      # пересобрать только эти две
```

Сборка кладёт PDF в `pdf/`, обновляет `manifest.json` и `index.html`.

Готовые PDF **закоммичены в репозиторий**, поэтому боту reportlab не нужен —
он просто отдаёт файлы с диска.

## 3. Как добавить свою шпаргалку

### Шаг 1. Создай файл `content/moya_tema.py`

```python
# -*- coding: utf-8 -*-
from neocheat.blocks import Callout, Formula, H, KV, Note, OL, P, Sheet, Table, UL

SHEET = Sheet(
    id="moya_tema",                       # латиницей, станет именем файла moya_tema.pdf
    title="Название шпаргалки",
    subtitle="Подзаголовок через · точки",
    category="Дыхание",                   # раздел меню в боте
    button="🫁 Короткая подпись кнопки",
    order=25,                             # чем меньше, тем выше в меню
    summary="Одна строка описания для меню и index.html.",
    blocks=[
        H("1. Первый раздел"),
        P("Обычный абзац. Можно <b>жирным</b>."),
        Table(
            head=["Колонка", "Ещё колонка"],
            widths=[2, 3],                # относительные доли ширины
            align="lc",                   # l / c / r на каждую колонку
            rows=[
                ["Значение", "!! красная ячейка"],
                ["Значение", "+ зелёная ячейка"],
            ],
        ),
        Callout("danger", "Заголовок предупреждения", "Текст."),
    ],
    sources=["Клинические рекомендации МЗ РФ «…»"],
)
```

### Шаг 2. Впиши имя модуля в `content/__init__.py`

```python
MODULES = [
    "rodzal",
    "moya_tema",   # ← сюда
    …
]
```

### Шаг 3. Собери

```bash
python build.py
```

Всё. Шпаргалка появится в PDF, в `manifest.json`, в меню бота и на `index.html`.

## 4. Справочник по блокам

| Блок | Для чего | Пример |
|---|---|---|
| `H("текст")` | Заголовок раздела — синяя плашка | `H("3. Дозы")` |
| `P("текст")` | Абзац | `P("Общий билирубин, мкмоль/л.")` |
| `UL("а", "б")` | Маркированный список | |
| `OL("шаг", "шаг")` | Нумерованный список — для алгоритмов | |
| `Table(head=…, rows=…)` | Таблица | см. ниже |
| `Callout(тон, заголовок, текст)` | Выделенный блок с цветной полосой слева | `Callout("danger", "Стоп", "…")` |
| `Formula("формула", "пояснение")` | Формула в рамке по центру | |
| `KV(("ключ","значение"), …)` | Компактная сетка пар в две колонки | |
| `Note("текст")` | Мелкая серая сноска | |
| `Rule()` | Тонкая линия | |
| `Spacer(6)` | Вертикальный отступ | |
| `PageBreak()` | Принудительный перенос страницы | |

**Тона** для `Callout` и подсветки: `info` (синий), `ok` (зелёный),
`warn` (жёлтый), `danger` (красный), `muted` (серый).

### Подсветка ячеек таблицы

Маркер ставится **в начало текста ячейки, через пробел**. В PDF он не виден.

| Маркер | Цвет |
|---|---|
| `"!! текст"` | красный |
| `"! текст"` | жёлтый |
| `"+ текст"` | зелёный |
| `"~ текст"` | синий |

Пробел обязателен — иначе `+15 мл` и `~2 ч` превратились бы в подсветку.

### Строка-подзаголовок внутри таблицы

Если элемент `rows` — не список, а **строка**, он растягивается на всю ширину
таблицы и работает как разделитель группы:

```python
Table(
    head=["Категория", "Критерий"],
    rows=[
        "!! Абсолютные показания",       # ← красная строка-разделитель
        ["Клиника", "Энцефалопатия"],
        "! Относительные показания",
        ["Динамика", "Прирост 6,8–8,5"],
    ],
)
```

### Спецсимволы

Писать `<`, `>` и `&` можно как есть — движок экранирует их сам,
пропуская только теги разметки `<b>`, `<i>`, `<u>`, `<br/>`, `<font>`,
`<super>`, `<sub>`. То есть `Hb < 100 г/л` и `<b>жирный</b>` в одном
абзаце работают одновременно.

## 5. Мини-приложение со шкалами

Шкалы живут отдельным мини-приложением в `scales/`, рядом с калькулятором
парентерального питания, но независимо от него: `…/tpn/scales/` — шкалы,
`…/tpn/` — питание. Каждая кнопка в боте открывает сразу нужный экран,
без вкладок и лишнего тапа. Три шкалы: **nSOFA**
(полиорганная дисфункция, из приложения Г1 КР «Сепсис новорождённых»),
**NIPS** (острая и процедурная боль) и **N-PASS** (боль, возбуждение
и глубина седации).

Пункты отмечаются кнопками, сумма и трактовка считаются на лету.
Повторное нажатие снимает выбор. N-PASS двусторонняя: положительная
сумма — боль, отрицательная — седация, поправка на недоношенность
прибавляется только к баллу боли.

### Один источник цифр

Шкалы лежат в **`data/scales.json`**, и из него берут данные оба:

| Кто | Как |
|---|---|
| PDF-шпаргалка «Шкалы оценки» | `content/_data.py` строит таблицы при сборке |
| Мини-приложение | `build.py` генерирует `scales/scales.js` |

Диапазоны трактовки выводятся из границ полос, а не переписываются руками,
поэтому таблица в PDF и подсказка в приложении не могут разойтись.

### Пороги билирубина

Расчёт порогов из проекта убран: у постели хватает таблиц в шпаргалке по ГБН.
Сами данные остались в **`data/bilirubin.json`** — из них `content/_data.py`
строит таблицы фототерапии, интенсивной ФТ и ОЗПК в PDF.

Где менять:

```jsonc
// data/bilirubin.json
"scales": {
  "kr_rf": {
    "hour_bands": [ {"max": 24}, {"max": 48}, … {"max": null} ],
    "ga_bands": [
      { "ga_max": 26, "label": "22–25 нед",
        "phototherapy": [86, 86, 86, 103, 120, 137],
        "intensive":    [103, 137, 137, 154, 171, 171],
        "exchange":     [137, 171, 205, 222, 222, 222] },
      …
    ]
  }
}
```

Сборка проверяет согласованность: длину рядов и лестницу
`станд. ФТ < интенс. ФТ < ОЗПК` в каждой клетке.

## 5.1. Источники: реестр клинических рекомендаций

`data/guidelines.json` — выгрузка рубрикатора МЗ РФ (`cr.minzdrav.gov.ru`)
по профилю «Неонатология»: ID, название, дата размещения, ссылка.

Шпаргалка ссылается на КР по ID, а строка источника собирается сама:

```python
sources=D.kr_sources("917_1", "916_1", "596_3") + [
    "Свободный текст, если нужен",
]
```

даёт в PDF:

> — Клинические рекомендации МЗ РФ «Гипербилирубинемия недоношенных» —
> ID 917_1, размещены 04.06.2025. https://cr.minzdrav.gov.ru/preview-cr/917_1

Если КР обновится, достаточно заменить `guidelines.json` новой выгрузкой
и пересобрать — даты и ссылки обновятся во всех тринадцати PDF сразу.
Неизвестный ID роняет сборку, так что опечатка не проедет незамеченной.

Текст самих КР можно скачать напрямую:
`https://apicr.minzdrav.gov.ru/api.ashx?op=GetClinrecPdf&id=917_1`

## 6. Подключение к телеграм-боту

### Вариант A — запустить готового бота

Весь бот уже собран в `bot/app.py`: поиск по рекомендациям, шпаргалки,
дозы, шкалы, калькулятор питания, меню команд и справка.

```bash
pip install -r requirements-bot.txt
export BOT_TOKEN=123456:AA...
python -m cheatsheets.bot.app
```

| Команда | Что делает |
|---|---|
| `/start` | меню и клавиатура |
| любой текст | поиск по 57 КР: «желтуха», «ГБН», «P23.0», даже в латинской раскладке |
| `/search`, `/kr` | то же командой и реестр рекомендаций по разделам |
| `/doza гентамицин 1200` | схема по ГВ и доза в мг на эту массу |
| `/shpory` | разделы → шпаргалка PDF в чат |
| `/scales`, `/tpn` | мини-приложение на нужной вкладке |
| `/materials`, `/about`, `/help` | список ссылок, о проекте, справка |

Переменные окружения: `BOT_TOKEN`, `TPN_WEBAPP_URL`, `SCALES_WEBAPP_URL`,
`CHANNEL_URL` (необязательная — без неё команды `/channel` нет).

Прогнать всё это без сети и без токена:

```bash
python tests/test_bot.py
```

### Вариант Б — встроить в свой код бота (три строки)

Скопируй папку `cheatsheets/` в репозиторий бота и добавь:

```python
from cheatsheets.bot.scales_router import scales_router
from cheatsheets.bot.aiogram_router import cheatsheets_router
from cheatsheets.bot.search_router import search_router

dp.include_router(scales_router)
dp.include_router(cheatsheets_router)
dp.include_router(search_router)   # ПОСЛЕДНИМ: ловит любой текст
```

Порядок важен: `search_router` отвечает на свободный текст, поэтому всё,
что должно срабатывать раньше, подключается выше него.

Кнопки мини-приложений — `bot/keyboard.py`, текст справки — `bot/help_text.py`.

Расчёта шкал текстом в чате нет намеренно: набирать команду с аргументами
у постели пациента неудобно, всё считается в мини-приложении.

Адреса мини-приложений задаются переменными окружения `SCALES_WEBAPP_URL`
и `TPN_WEBAPP_URL`.

### Вариант B — любой другой фреймворк

`bot/catalog.py` не зависит от телеграм-библиотеки:

```python
from cheatsheets.bot.catalog import Catalog

catalog = Catalog()
catalog.categories()              # ['Родзал и реанимация', 'Дыхание', …]
catalog.by_category("Дыхание")    # [Cheatsheet, …]
catalog.get("gbn").path           # путь к PDF на диске
catalog.search("озпк")            # поиск по названию и описанию

# кэш file_id, чтобы не заливать один PDF по многу раз
catalog.file_id("gbn")                     # None или сохранённый file_id
catalog.remember_file_id("gbn", file_id)   # запомнить после первой отправки
```

Кэш инвалидируется автоматически: в нём хранится `sha256` файла, и после
пересборки PDF старый `file_id` перестаёт использоваться.

### Вариант C — ссылкой, без заливки файла

Если репозиторий опубликован через GitHub Pages, PDF доступны по прямым ссылкам:

```
https://jew1ik.github.io/tpn/cheatsheets/pdf/gbn.pdf
https://jew1ik.github.io/tpn/cheatsheets/            ← страница со всеми
```

Ссылка на каждую шпаргалку лежит в `manifest.json` в поле `url`.
Базовый адрес задаётся константой `PAGES_BASE` в `build.py`.

## 6.1. Развёртывание на сервере

Полная инструкция — [`deploy/README.md`](deploy/README.md). Коротко:

```bash
# готовый бот с нуля (спросит токен, поставит сервис, запустит)
sudo ./cheatsheets/deploy/install-bot.sh /opt/postneo

# только модуль, если бот свой
./cheatsheets/deploy/install.sh /opt/postneo
./cheatsheets/deploy/update.sh  /opt/postneo postneo-bot
```

`install-bot.sh` идемпотентен: повторный запуск — это обновление.
`install.sh` не трогает код бота: кладёт `cheatsheets/` рядом, делает бэкап
прежней версии и переносит кэш `file_id`. reportlab на сервере не нужен —
PDF собраны заранее.

**Кнопка мини-приложения работает только по HTTPS с валидным сертификатом**,
на голый IP Telegram её не откроет. Проще всего включить GitHub Pages;
если нужен свой домен — рядом лежит конфиг nginx.

## 7. Что важно помнить про содержание

Шпаргалки — **памятки для быстрой сверки**, а не нормативный документ.
Дозы, пороги и схемы нужно сверять с действующей редакцией клинических
рекомендаций МЗ РФ, инструкциями к препаратам и протоколами отделения.
Источники перечислены в конце каждого PDF, дисклеймер — в подвале каждой страницы.

Правки вносятся в файл `content/<id>.py` и вступают в силу после `python build.py`.
