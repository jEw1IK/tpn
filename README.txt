POSTNEO Калькулятор — версия для компьютера
Windows 10/11, 64 бит. Интернет не нужен.

Это калькулятор питания с печатью листа назначений. Пациентов он не
хранит и входа не требует. База пациентов отделения ведётся на сервере:
https://89.169.32.9/kart/ — там же логины врачей и подписи листов.

УСТАНОВКА
1. Распакуйте архив целиком в любую папку. Права администратора
   не нужны.
2. Запустите POSTNEO-Kartochki.exe. При первом запуске программа
   скопирует себя в папку пользователя (AppData\Local\POSTNEO\program),
   если лежит на сетевом диске, флешке или в загрузках: оттуда она
   стартует за секунды и сама обновляется. На рабочем столе появится
   ярлык «POSTNEO Карточки», дальше запускайте им. Архив после этого
   можно удалить.
3. Если Windows пишет «Система защитила ваш компьютер»: нажмите
   «Подробнее», затем «Выполнить в любом случае». Это предупреждение
   про программу без платной цифровой подписи, оно показывается один раз.
4. Откроется калькулятор. Заполните лист, нажмите «Печать» или Ctrl+P.

СЛУЖЕБНЫЕ ФАЙЛЫ
C:\Users\<имя>\AppData\Local\POSTNEO\
   program\         сама программа (сюда она копирует себя при первом запуске)
   kart\logs\       журнал; при сбое пришлите server.log разработчику

ОБНОВЛЕНИЕ
Закройте окно, распакуйте новый архив поверх старой папки. Данные
хранятся отдельно и при обновлении не трогаются.

КАК ЭТО РАБОТАЕТ
Программа поднимает локальный сервер на этом же компьютере
(адрес 127.0.0.1, снаружи недоступен) и открывает его в окне
Microsoft Edge или Chrome без адресной строки. Когда окно закрыто,
сервер останавливается сам. Печать листов — через меню окна или Ctrl+P.
